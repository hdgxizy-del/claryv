# Clary Visuals — مشروع أولي

**الإصدار المستهدف:** Minecraft Java 1.21.5 / Fabric / Java 21

هذا أرشيف **مصدر مشروع أولي** وليس ملف JAR مبنيّاً أو موداً مكتملاً. يتضمن قائمة بنفسجية تفتح بزر Right Shift على الكمبيوتر، وفئات وخيارات واجهة تجريبية.

## مهم جداً
- اختيارات Small / Purple / Transparent وغيرها حالياً عناصر واجهة فقط؛ لا تغيّر نموذج الكريستال أو خاماته بعد.
- مفاتيح التأثيرات حالياً تحفظ حالتها داخل الجلسة فقط ولا تغيّر جميع تأثيرات اللعبة.
- واجهة الأزرار مصممة أساساً لتعمل مع إدخال Java المعتاد. في PojavLauncher على Android قد تحتاج إلى تعيين مفتاح Right Shift أو إضافة زر لمس عبر إعدادات التحكم.
- لا يوجد Gradle Wrapper مرفق. البناء يتطلب كمبيوتر عليه JDK 21 وGradle، واتصال إنترنت لتنزيل اعتماديات Fabric.

## البناء على الكمبيوتر
1. ثبّت JDK 21.
2. ثبّت Gradle متوافقاً (8.12 أو ما يقبله Fabric Loom 1.10.5).
3. افتح مجلد المشروع في الطرفية.
4. شغّل `gradle build`.
5. إذا نجح البناء، ستجد ملف JAR داخل `build/libs/`.
6. انسخ الـ JAR إلى مجلد `mods` في بيئة Minecraft 1.21.5 Fabric التي تحتوي على Fabric API.

## الخطوة التالية لإكمال التصميم
تحتاج إضافة خامات PNG فعلية للكريستال/الأوبسيديان/النار/التوتم، ثم ربط الاختيارات بموارد اللعبة أو بنقاط رسم مخصصة. يلزم اختبار فعلي على 1.21.5 وPojavLauncher قبل وصفه بأنه متوافق بالكامل.
